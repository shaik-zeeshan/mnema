# GPUI app: honest gap audit (2026-11-10)

Written after the founder found recording didn't start in the signed dev app. "Built"
below means rendered and tested on fixture data; "wired" means it runs on the real backend.

## A. Not wired to the backend (being fixed: wiring passes A and B)
113 `// shortcut:` stubs in `apps/desktop-gpui/src` (chat 28, settings 29, shell 19, timeline 9,
small 9, insights 7, quick_recall 5, others 7). Record/Pause/Stop, all Timeline data, all of
Chat, many Settings saves.

## B. Svelte commands with no GPUI counterpart at all (name scan: 52 of 207)
Some are host-only or renamed; the real feature holes are:
- MCP: server secrets set/clear, OAuth begin/disconnect, node check, warm connectors, custom connector form, tool list.
- Deepgram: key save/clear/test/auth status, the consent dialog.
- Models: cancel OCR download, delete semantic/speaker models, download progress rows.
- Speakers: delete person profile.
- Licence: reset devices, the deep-link receipt modal, the licence banner in the shell.
- Updates: set channel, install (wired in S16; verify), relaunch request.
- Jobs: get/list by processor, retry now (debug job inspector + processor drill-in).
- One-time prompts: shown/dismiss/complete (e.g. the app-privacy exclusion prompt).
- Retention: preview cleanup. Logs: delete general log (verify).
- Clock: `user_context_stamp_local_offset` (AI temporal grounding needs it on start/focus).
- Reminder: snooze for today. Notifications: clear one.
- Apple Speech permission request/settings pane; browser-URL accessibility pane; capture privacy pane.

## C. Built but simplified
- FrameDetailModal (no frame image/OCR text), Chat timeline answer block, Insights detail modals
  (no category/focus correction), receipt audio + turn list, onboarding Models tab split.
- Hover/focus colour transitions are instant; popovers don't scale in; no letter-spacing; no blur (ruled).
- Persisted appearance (light/dark) isn't applied at startup; it follows the OS.

## D. Never verified
- Nothing has been driven in the real app by a person except the founder's first try.
- `scripts/startup-log-diff.sh` never run. Real recording, sleep/wake, lock, low disk: untested in GPUI.
- §5 budgets not measured: cold start vs Tauri, idle power vs Tauri, keystroke-to-paint.
- Updater end to end with a real identity; tray menu by click; notification actions.
- Tauri app itself after the extraction: no real recording smoke since S3 (only tests).

## E. Engineering gaps
- app-core doesn't enable semantic-search's `metal` feature: the GPUI app embeds on CPU (heat/battery).
- No CI job runs `cargo test -p app-core` or `-p mnema-gpui`; ~1,300 tests moved out of the Tauri job.
- `SUPPORTS.md` has no "GPUI app: macOS only" note. Third-party licences don't credit GPUI crates.
- Updater: no admin fallback for a non-writable install folder; Settings channel switch unwired.
- Unexplained offscreen 500x500 window with sharingState 1.
- Branch is local only (never pushed); 60+ commits exist on one machine.
