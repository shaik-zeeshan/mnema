Typography · 3 pairings

One sans for the interface, one mono for the record.

Each column renders the same slice of Mnema — an Overview headline, its stats, a timeline readout and a settings row — in a different pairing. All six faces are OFL-1.1, self-hosted from fonts/ (latin subset, variable weight, 23–47 KB each), so they can ship inside the app bundle with no network request.

Chosen

A · Hanken Grotesk + Spline Sans Mono. It is the marketing site's pair (apps/web/DESIGN.md), so app and site read as one brand. Hanken's open apertures and slightly humanist forms stay calm and legible at 11–13px UI sizes, where Geist feels colder and Schibsted's tight spacing crowds. Spline Sans Mono has soft, wide numerals that make timestamps and durations scan in columns without the shout of Martian.
