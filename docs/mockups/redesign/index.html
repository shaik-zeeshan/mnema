Redesign kit · v1

A quieter instrument for remembering.

Shared shell and components for the Timeline, Insights, Chat and Settings mockups — one button system, one choice control, one date input, one type scale. Every surface below is drawn from the app's real tokens; each component block is shown in both themes side by side.

Font pairings
Design principles
  1. Near-black, not black. Depth comes from surface lightness and 1px hairlines — flat, no bevels, no inner highlights, no shadows.
  2. Green is a signal. ≈10% budget: live state, matches, selected marks, the one primary button, focus. Never a large fill.
  3. Sans carries the interface. Hanken Grotesk for titles, prose, buttons, nav and labels; Spline Sans Mono only for the record — data, times, kickers.
  4. Two control heights. 26 and 32px. Buttons, segmented, date capsule and inputs all snap to them.
  5. Spec rows over card grids. Asymmetric, left-aligned; one dominant idea per view.
  6. Ease-out, no bounce. Transform/opacity only; one staggered reveal per load; honor reduced motion.
