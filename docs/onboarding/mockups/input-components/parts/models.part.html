Implementation notes
  • Replaces ChangeSettingsScreen.svelte:322 (transcription model <Select>) and :370 (Semantic Search model <Select>). The family group already ships at :317 (transcriptionProviderOptions over Segmented), so this is delete the Select, add a second Segmented under it — the real lib/components/Segmented.svelte, whose radiogroup roles, roving tabindex and focus ring the markup here is a port of.
  • Semantic Search has no family group today: build it from c.semanticSearchModelOptions grouped by language coverage (English / Multilingual). No Off segment — an earlier pass folded the row’s Switch (:380) in as a first segment; that put one setting in two places once the switch chain existed, so on/off stays with the chain and this group answers only which language coverage. With the feature off, no segment is active. onSemanticEnabledChange is still needed — the budget escape calls it.
  • The variant sub-group renders only when a family has >1 build, but its row is height-reserved, so switching family never moves the strip or the footer. Apple Speech and Off keep the row and fill it with the family’s one-line fact. Apple Speech carries OS_MANAGED_OPTION_VALUE and no byte figure at all.
  • Sub-group selection is remembered per family, so switching Whisper → Parakeet → Whisper does not silently reset a deliberate Medium back to Base.
  • The strip’s third cell is per-picker (transcription = memory while running, semantic = languages) because those are the facts each list actually has. Backend gap: no manifest carries a memory figure — the transcription column is editorial text keyed by family, and Parakeet int8 has no honest number, so it prints “below Parakeet full precision” rather than inventing one. If it should be data, it needs a field on the transcription manifest.
  • The footer replaces the per-row downloadNote(...) sentences (:307, :344, :359) and the semanticShare percentage at :363. The bar is aria-hidden decoration; the total line beneath it is the text of record. Free disk needs a real figure (statvfs on the capture volume) — today the screen has none.
