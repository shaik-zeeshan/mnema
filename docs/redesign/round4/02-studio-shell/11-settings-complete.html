11Settings, whole — all 96 rows in one scroll

Every settings row the app registers, drawn in this direction's settings shape: no navigation rail, one scroll, a filter field in the tool strip, group headers as the address, and the inspector carrying the focused setting's detail. The structure is not invented — it is settings/groups.ts and settings-index.ts read straight down: 5 groups, 19 sections, 96 rows, the same count the ⌘F index test enforces. First frame is the true 1100×720 window mid-scroll; the second unrolls the whole content column so every group can be checked off at once. Rows the app only renders under a condition carry a only when… tag rather than being quietly dropped.

1100 × 720 — the real window, scrolled into Intelligence. The group header (Intelligence) is pinned; the section sub-header scrolls under it. The focused row is the transcription provider; the inspector shows what that provider means on this Mac, its ⌘F terms, and the session's changes. Per G7 the status strip carries the save chip and no Undo — settings-Undo is out for v1, which is a deliberate departure from pages 05 and 06.

Where the G-decisions overrode the earlier pages, and what the source says.

G7 · no Undo

Pages 05 and 06 put an Undo button in the status strip. Settings-Undo is out for v1, so the strip here carries the save chip alone. Row echo plus chip is the whole pattern.

G8 · no temperature, no ETA

Page 06's OCR control claims +3 °C and a clear-by time. Neither appears here. Consequence lines name disk, index size, model size, queue depth and token estimates — quantities the app holds.

G9 · unnamed external conflicts

The shortcut group names an in-app owner (“already used by Summon Quick Recall”) and says only “another app” otherwise. macOS cannot enumerate other apps' hotkeys.

G10 · semantic search off

Drawn OFF with the price stated before the switch and no coverage meter. Note the source's stored default is true — but with no model installed it embeds nothing, so “off” is what the user sees. Worth reconciling.

Why this shape holds at 96 rows and not just at 48. A rail needs 19 entries to reach every section, or 5 entries plus a second level of scrolling inside each. The filter reaches all 96 in two keystrokes and does not care which group a setting is in — which is the state a user is actually in when they open Settings. The group bars exist so that scrolling still teaches the structure: they are the rail, laid on its side, inside the content.
