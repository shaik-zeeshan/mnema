11Settings — the whole thing

Pages 05 and 06 showed the settings shell. This one shows the whole surface: five toolbar tabs, thirty-five real groups, every one of the 97 indexed rows, drawn as bento tiles on the same two-column grid. Each tab below is its pane unrolled — the window shows about 640px of it at a time and the rest scrolls under the sticky bar. Nothing here is invented: if a row is not in settings-index.ts, it is not on this page.

General — 3 groups + the 4 shortcut categories

Seven tiles. The shortcut categories are wide (2×1) because a keycap recorder plus a conflict line does not survive a one-column tile. Twenty-one shortcut editor rows live in those four tiles and are deliberately not in the row index — they are one indexed row, Global shortcuts, plus a binding table.

What this pane deliberately does not do

Not drawnWhy
A left railNineteen sections would make a nineteen-item rail. Five tabs plus ⌘F row-filtering covers the same ground; the sub-section ids survive as ⌘F breadcrumbs and ?tab= deeplinks.
A bottom save barG7. Autosave is a chip in the top-anchored sticky bar plus a per-row Saved ✓ echo. Failure is the only state that persists and it also raises a toast.
Settings-UndoG7 again — cut for v1. The chip and the row echo answer the anxiety; an undo stack is speculative machinery.
Any °C figureG8. OCR's duty cycle shows both halves of the cycle and the backlog; it makes no temperature claim.
A named external shortcut conflictG9. In-app conflicts are named with their owner. External register-failures cannot be — macOS has no API to enumerate another app's hotkeys, so the copy stays honest and vague.
A semantic-search coverage meter in the off stateG10. Off is the shipping default; the meter renders only once it is on. The off row states the price instead, computed from the real frame count.
Round model sizesG8. Sizes come from the corrected registry — speakrs is 419 MB, and the semantic model's ~137 MB is marked approximate because the registry genuinely does not pin it.
