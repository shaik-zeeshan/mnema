Deviations

Where this direction bends a rule, on purpose

RuleWhat this direction doesWhy it is defensible
“Six type sizes exist” The masthead outside every app window uses 26px for its headline. The masthead is presentation furniture for reviewing the mockups; nothing inside a rendered window leaves the six roles.
Quick Access is 1120×720 with Search and Ask inside Held. But “ask about this screen” renders as a 640px floating bar over the desktop instead of the window. It is the same Quick Access window collapsing, not a new window: the same process, the same conversation, and ⌘O restores it to full size. The feature's whole point is that the window gets out of the way.
Search and Ask both live in Quick Access Held, but there is no segmented control — Ask is the top-ranked row and taking it retitles the surface. The founder asked for them to be clearly different. A segment makes them look like two tabs of one thing; a ranked row plus a full surface transform makes them two different answers to two different questions.
Settings sidebar Removed entirely — five horizontal tabs, one scroll, ⌘F filter. The founder called the rail “a bit weird”. Raycast ships exactly this shape natively (NSToolbar tabs, no rail) and it removes the “which bucket is this in?” problem instead of re-decorating it.
Context attachment should be one muted label, no thumbnail A 42 × 26 thumb sits beside the label in the HUD. The rule targets hero thumbnails that cost the panel's width. At 42px it costs 6% of the bar and answers “which screen?” on a multi-display Mac, which a text label cannot.
~12 bordered containers per window Every page lands at 1–3. Depth is carried by surface steps and the two chrome bars; the only true borders are the window itself, floating things (menu, drawer, HUD) and media frames.
