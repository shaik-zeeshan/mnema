The receipt is a floating sheet — so it may be glass — but its stage, its transcript and its filmstrip are all opaque plates, because pixels and prose never sit on material.

Honesty audit — what this page refuses to draw

No app icon on a river card

Activity carries title, summary, category, focus and an evidence list — no app name, no window title, no URL. Those exist only per frame, inside the receipt. A row of app glyphs in the river would be invented.

No focus score, no percentage per card

focus is a three-value enum — deep / mixed / distracted, rendered Deep / Mixed / Scattered. There is no number behind it, so the chip carries a word.

No OCR text in the receipt

The frame record has ocrText, but the receipt only tests it for emptiness. Showing a paragraph of recognized text would be a new surface, not a mockup — so the chip stays a chip.

“3 capture segments” is a heuristic

Frames carry no segment id; the count comes from a 90-second-gap rule in the frontend. It is drawn because the shipping component draws it — but it is not a queried fact.
