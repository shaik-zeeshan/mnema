03 · Quick Access — Search

Look at: Quick Access is a real HUD — a floating glass panel over a dimmed desktop, not a second window pretending to be an app. Search's identity is graphite chrome + a grid of opaque frame plates: the material never touches the results, so screenshots and captions stay on solid surfaces. The mode chip overhangs the panel's top-right corner like a tab, and asking is the first row of the result list (the Spotlight move), so the two modes are one keystroke apart without pretending to be the same surface.
