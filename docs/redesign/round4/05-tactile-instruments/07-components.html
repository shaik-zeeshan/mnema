2 · The instruments — one anatomy, six faces

The anatomy is fixed: a header carrying the name and the live value, a recessed well holding the physical control, and a readout that states the consequence in user units with a denominator. The readout slot exists at rest and has a minimum height, so a changing consequence never reflows the rows below it. An instrument appears only where the value is physical — six of them exist in the whole app.

01 Overview One --t-display (6:42). Tile labels are 10px mono eyebrows, so no two tiles compete. Media leads the grid. 12px inset = 12px gutter at both widths. Accent used 4× (today's bar, the week's bar, one conviction dot row, the coverage fill). Every tile has a designed empty reading; the gauge has a no-data face. Material toolbar, full-row accent in the switcher, tabular numerals everywhere. 1 — the window ring. Tiles are fills.
02 Timeline The readout clock is the display type; the rail is the only saturated object. 12px rail inset, 8px between rail / lane / readout. Recording red only on the active tick and the selected audio bar. Source colours are the shipping mic/sys pair. Rerun shows progress in place; disabled refresh; hover ghost-playhead and time bubble; the jump menu disables days with nothing in them. NSMenu anatomy for the jump menu; 24px menu rows; ⌘ column right-aligned. 3 — window, jump menu, hover bubble (both float).
03 Search The grid is the payload; chrome is monochrome so the frames carry all the colour. 20px inset / 16px gutter — the fixed-window exemption, 3 × 349 exactly. Accent twice: the selected cell's ring and the Ask row. Selected, hover affordance overlay, no-match with a searched-coverage readout. Overlay scrollbars, default cursor on the grid, section headers as bare labels. 2 — window, the Ask row.
04 Ask + frame One prose column at 68ch; evidence is smaller and to the side. 20px inset; the floating stack keeps a 12px gap between its two pieces. Ask's identity is the accent-tinted field — the one colour difference from Search. Streaming with a live tool trace, stale-frame warning, hidden panel, disabled send. Materials only where macOS uses them: the floating pieces, and nowhere else. 4 — window, display, control pill, answer panel (three of them float).
05 Settings Section title 17px, group headers 10px mono, rows 13px. Instruments outrank rows by having a value in the header, not by being louder. 24px between sections, 8px between groups, 660px column. Accent on the active tab, the save chip, and the two instrument values. Danger only on Delete Recent. Row-level saved echo, saving, undo, failed. Shortcut recorder at rest / armed / conflicting. Toolbar tabs instead of a rail; sticky opaque group headers; popup buttons with the accent chevron block. 1 — the window ring.
06 Intelligence Three instruments among nine stock rows; the contrast is the hierarchy. Identical to 05 — same shell, same column. Full-row accent selection on the chosen model. 1 — the window ring.
